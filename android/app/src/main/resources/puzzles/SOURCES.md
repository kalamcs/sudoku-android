# Puzzle bank sources

- Imported Medium, Hard and Extreme template IDs refer to Grant McLean's
  [Sudoku Exchange Puzzle Bank](https://github.com/grantm/sudoku-exchange-puzzle-bank/tree/d8c8ebaee0c08c412cfba96af1923dfa61c83317),
  revision `d8c8ebaee0c08c412cfba96af1923dfa61c83317`. The published
  grades are used to shortlist templates from `hard.txt` and `diabolical.txt`.
  The bank credits [QQWing](https://qqwing.com/) and dedicates its data to the
  public domain under the [Unlicense](https://github.com/grantm/sudoku-exchange-puzzle-bank/blob/d8c8ebaee0c08c412cfba96af1923dfa61c83317/LICENSE.txt).
- Medium template IDs beginning with `local-` identify boards generated by
  `scripts/MediumPuzzleCandidates.java` using this project's Kotlin solver.
- Ratings use [Sukaku Explainer v1.18.1](https://github.com/SudokuMonster/SukakuExplainer/releases/tag/v1.18.1),
  based on Nicolas Juillerat's Sudoku Explainer and gsf's batch rater.
  The preparation script pins the JAR SHA-256 and uses the documented
  [classic SE technique settings](https://github.com/SudokuMonster/SukakuExplainer/wiki/Batch-mode-command-line-parameters).
  The rater runs in WSL during bank preparation.
- Suuudokuuu's
  [difficulty guide](https://www.suuudokuuu.com/guides/sudoku-difficulty-rating)
  and [hardest-puzzle article](https://www.suuudokuuu.com/hardest-sudoku-puzzles)
  informed the difficulty change.

The TSV records the level, template ID, rating in tenths, givens and solution
for each original grid and its three verified variations. The expansion adds
300 templates per level sampled across the source ratings and rejects
equivalent grids across all levels. Equivalence covers row and column
permutations that preserve boxes, transposition and digit relabeling.

Each packaged difficulty file uses 103 bytes per template. The first byte is
the base rating, followed by 81 bytes for the givens and solution. Each
nibble stores one cell and the high nibble comes first. Three seven-byte
entries follow. Each contains the variant rating and a six-byte little-endian
number encoding a row order, column order, transpose flag and digit mapping.
JVM tests reconstruct each rated grid from the files and count solutions up
to two.

## Regenerate the bank in WSL

Use the Java and Android environment in the project README. The commands
below use Python 3 and the Kotlin stdlib from this project's Gradle cache.

```bash
se_work=$(mktemp -d)
se_source=https://raw.githubusercontent.com/grantm/sudoku-exchange-puzzle-bank/d8c8ebaee0c08c412cfba96af1923dfa61c83317
curl -fsSL "$se_source/hard.txt" -o "$se_work/hard.txt"
curl -fsSL "$se_source/diabolical.txt" -o "$se_work/diabolical.txt"
curl -fsSL https://github.com/SudokuMonster/SukakuExplainer/releases/download/v1.18.1/SukakuExplainer.jar \
  -o "$se_work/SukakuExplainer.jar"
(cd android && ./gradlew :app:compileDebugKotlin)
se_kotlin_stdlib=$(find "${GRADLE_USER_HOME:-$HOME/.gradle}/caches/modules-2/files-2.1/org.jetbrains.kotlin/kotlin-stdlib/2.2.21" \
  -name 'kotlin-stdlib-2.2.21.jar' -print -quit)
"$JAVA_HOME/bin/java" -Xmx384m \
  -cp "android/app/build/tmp/kotlin-classes/debug:$se_kotlin_stdlib" \
  scripts/MediumPuzzleCandidates.java 900 > "$se_work/medium-candidates.txt"
python3 -B scripts/prepare-puzzle-bank.py "$se_work/SukakuExplainer.jar" "$se_work" \
  "$se_work/medium-candidates.txt" "$se_work/se-templates.tsv" --expand \
  --checkpoints "$se_work/checkpoints"
python3 -B scripts/pack-puzzle-bank.py "$se_work/se-templates.tsv" "$se_work/packed"
(
  cmp "$se_work/se-templates.tsv" android/app/src/main/resources/puzzles/se-templates.tsv || exit
  for level in medium hard extreme; do
    cmp "$se_work/packed/$level.sudoku" "android/app/src/main/assets/puzzles/$level.sudoku" || exit
  done
)
```

The `cmp` commands check reproducibility. After an intentional bank update,
copy the TSV and packed files into their respective directories and run
`./android/gradlew -p android :app:testDebugUnitTest` to verify the packaged data
and its solutions.
