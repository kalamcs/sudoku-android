Hint

    How to play

    Fill the empty cells with 1–9. Each row, column, and 3×3 box must contain each digit once. Bold clues stay fixed. The boxes are numbered left to right, from the top row of boxes to the bottom.

    Solving strategies

    Naked single
    Check the row, column, and box of a cell. If they rule out every digit except one, fill in that digit.
    Hidden single
    Pick a missing digit in a row, column, or box. If it fits in only one cell there, place it in that cell.
    Locked candidates
    If a digit can only go in one row inside a box, rule it out in the rest of that row outside the box. The same idea works with columns and in reverse.
    Naked pair
    If two cells in a row, column, or box have the same two candidates, those digits belong in those cells. Cross both off elsewhere in that row, column, or box.
    Proof by contradiction
    Consider a candidate temporarily. If it forces a rule violation or leaves no way to finish the grid, rule it out. If only one candidate survives, place it.

    Use Notes to track candidates. Hint checks your entries and explains a forced move when they’re correct.
